# 光影 · 相机实验室

打开仓库根目录的 `camera-simulator.html` 即可运行。推荐用 Chrome、Edge 或 Safari 打开；无需安装依赖，无需联网，图片、样式与脚本已嵌入 HTML。

## 操作

1. 点击顶部镜头类型：广角、标准、长焦、微距、鱼眼或变焦。下方同步显示对应镜头的原理说明。
2. 拖动焦距观察取景范围，拖动光圈观察景深与亮度，拖动对焦距离改变清晰平面。
3. 点击主体或背景对焦，也可按“自动对焦”回到主体。
4. 开启“主体运动”，比较快快门与慢快门的拖影。慢快门会提高亮度，可收小光圈使亮度相近再对比。
5. 改变“拍摄距离”移动机位，观察与固定机位变焦的区别。距离从理想镜头主平面计。
6. 微距模式中的“1∶1 近摄”设置理想薄透镜 `u = v = 2f`。这不是具体微距镜头前端的真实工作距离。
7. 点击“拍摄照片”生成成片预览，再点“保存 PNG”；也可右键或长按图像保存。

## 自定义照片

### 将整张照片放入取景器

点击“上传照片”选择本地图片，也可直接将文件拖入取景框。支持 JPG、PNG、WebP，单个文件不超过 20 MB。读取后保持原图比例缩小，最长边不超过 2400 像素，总像素不超过 400 万，以控制浏览器的内存占用。

上传后使用整张照片模式，默认花瓶会被替换。3∶2 取景器提供两种图片适配方式：

| 方式 | 效果 |
| --- | --- |
| 铺满画面 | 图片覆盖取景区域，比例不一致时裁掉部分边缘 |
| 完整显示 | 保留整张图片，比例不一致时画面会留边 |

标准镜头 50 mm、拍摄距离 3 m 是图片大小的参考设置。上传后可以继续改变镜头、焦距、光圈、快门、ISO 和对焦距离，观察取景、亮度、噪点与离焦的变化。图片本身保留原有的透视和清晰程度；模拟器不会从一张照片重建三维场景。

整张照片作为同一个平面处理，整幅图像统一离焦。它不识别人物、物体和背景各自的真实距离，也不能让原图中已经模糊的部分恢复细节。

### 添加独立主体

点击“上传主体”会自动进入分层模式，将主体作为独立图层叠加到背景上。建议使用带透明通道的 PNG 或 WebP，这样只显示主体轮廓；没有透明通道的图片会连同矩形背景一起显示。

| 控件 | 调节范围 | 用途 |
| --- | --- | --- |
| 主体大小 | 25%–200% | 调整主体在画面中的大小 |
| 横向位置 | −40%–+40% | 左右移动主体 |
| 纵向位置 | −40%–+40% | 上下移动主体 |
| 背景间距 | 0.5–15 m | 设定背景位于主体后方多远 |

分层模式使用所设定的主体距离和背景间距分别计算离焦。点击主体可对焦主体，点击背景可对焦背景；“自动对焦”回到主体。开启“主体运动”后，上传的独立主体也会产生与快门时间相关的运动拖影。

这些距离由控件设定，不是根据照片自动测量的真实深度。分层素材也不能还原照片中已经失去的细节。

### 保留或恢复素材

照片和主体只在浏览器本机读取和处理，不会上传到服务器。素材不会跨页面刷新保存，刷新或重新打开 HTML 后需要重新选择。

重置相机设置会保留已上传的素材。需要移除自定义照片和主体时，点击“恢复默认场景”，回到内置花园与花瓶场景。

## 适合对比的设置

| 要观察的效果 | 设置 |
| --- | --- |
| 背景虚化 | 标准镜头，50 mm，f/2.8，对焦 3 m |
| 更大的景深 | 光圈改为 f/5.6 或 f/8；手动增加曝光时间补偿亮度 |
| 高 ISO 噪点 | ISO 100 改为 3200，同时调快快门以控制亮度 |
| 慢快门拖影 | 开启主体运动，约 f/22、1/2 s、ISO 100 |
| 鱼眼映射 | 切换鱼眼，观察远离中心的直线弯曲 |
| 1∶1 成像 | 切换微距，再点“1∶1 近摄” |

## 成像模型

以 36×24 mm 全画幅传感器、理想薄透镜与单平面照片或分层场景作教学近似。分层场景中的主体和前景表面位于拍摄距离，默认花园背景位于主体后方 9 m；背景间距可在 0.5–15 m 范围内调整。整张照片模式中的图片视为一个平面，统一计算离焦。焦距、像距与主体投影使用毫米；景深清晰阈值为 0.03 mm。

`v = f s/(s-f)`；场景投影倍率为 `v/z`；离焦弥散圆直径为 `f²|z-s|/[N z(s-f)]`。由同一弥散圆阈值求得景深近界与远界，避免数字和画面不一致。微距亮度计算包含理想延伸曝光损失。

魚眼按 `r = fθ` 作等距映射，有限素材覆盖不代表真实 180° 视场；鱼眼的景深和离焦只显示中心近轴参考。背景高斯虚化、曝光、ISO噪点与运动模糊都是教学近似。素材的分辨率也限制极端微距放大的细节。本页未模拟具体镜头的衍射、像差、真实镜组结构、入瞳变化、传感器响应或完整三维遮挡。

镜头分类包括用途和结构两个维度：微距也可能是标准或长焦；变焦也可覆盖广角至长焦。固定机位变焦主要改变取景，常说的透视夸张或压缩通常与改变机位有关。

参考：[尼康焦距说明](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)、[斯坦福高斯成像](https://www-graphics.stanford.edu/courses/cs178-11/applets/gaussian.html)、[斯坦福景深演示](https://www.graphics.stanford.edu/courses/cs178/applets/dof.html)。
